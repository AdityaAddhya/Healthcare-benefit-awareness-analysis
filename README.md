# Healthcare-benefit-awareness-analysis
A data-driven case study investigating the 83% awareness gap in Indian SME healthcare benefits. Includes Root Cause Analysis (5 Whys), SQL activation tracking, and a proposed WhatsApp-first product intervention.
I developed a tracking framework to monitor the 14-Day Activation Rate. This script identifies segments with high "Awareness Gaps," allowing for targeted automated nudges to resolve the Channel Mismatch identified in my research.
